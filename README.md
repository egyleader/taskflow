# TaskFlow

A deliberately small pure-Dart CLI task manager. TaskFlow itself is not the
point -- it exists to give a realistic-but-small codebase for practicing
team git and GitHub workflows: feature branches, pull requests, merge
conflicts, rebases, cherry-picks, releases, and the rest of the collaboration
toolkit that's hard to practice solo.

If you're here to learn the app, you're in the wrong repo. If you're here to
get comfortable with PRs, conflicts, and history that doesn't scare you
anymore -- see **[CURRICULUM.md](./CURRICULUM.md)** for the full level-by-level
plan, and **[CONTRIBUTING.md](./CONTRIBUTING.md)** for the branch/commit/PR
conventions we use in this repo.

## Running it

```
dart pub get
dart run bin/taskflow.dart
dart test
```
